# Roadmap

Nothing on this page is built yet. It is a list of intentions, not promises.

| Idea | What it would do | Status |
|---|---|---|
| DontWorryBot goals interview | A short guided conversation about your goals (saving for something, paying something off, building a buffer), used to make the financial health score personal instead of one-size-fits-all | Designed, not built |
| More banks without AI | Built-in readers for other Singapore banks' statement layouts, like the DBS/POSB one | Not built |
| Automatic classification of unclear payees | Let the local model suggest categories for the Review list on DBS/POSB statements, still confirmed by the user | Not built |
| Windows verification | Try the double-click start file on real Windows laptops | Not done |
| Move the compound-interest calculator | It currently sits on the Upload page; it belongs under Utilities | Not done |

"Connect DBS" in the navigation is a placeholder page describing a possible future direction. Nothing
in this app connects to DBS or to any bank.
